# 소코반 마우스 이동 버전 (sokoban-mouse-controls)

인접한 칸을 마우스로 클릭해 플레이어와 상자를 6방향으로 움직이는 Java Swing 소코반입니다.
3D 카메라는 네 아이소메트릭 구도 사이에서 90°씩 회전합니다. 초반 1~3단계는 2D 탑뷰입니다.

원본 프로젝트: [wegoedod/sokoban_ssd](https://github.com/wegoedod/sokoban_ssd).
이 저장소는 [zb0535/sokoban_ssd](https://github.com/zb0535/sokoban_ssd)의 조작 변경 버전(`41b833c`)을 기반으로
마우스 이동, 클릭 대상 강조, 상자 도착 칸 미리보기와 90° 카메라 회전을 추가한 독립 작업본입니다.

소프트웨어시스템설계 팀 프로젝트. 고전 퍼즐 게임 소코반을 **3차원 격자 + 아이소메트릭(2.5D) 화면**으로 만든 Java 게임과, 그 설계 문서(요구사항·UML)를 담은 저장소다.

## 소개

- 플레이어와 상자가 x, y, z **6방향**으로 움직인다. 중력·바닥이 없어 모든 빈 칸이 공중이다.
- 상자를 목표 칸에 모두 올리면 클리어. 구멍 칸에 상자를 밀어 넣으면 상자와 구멍이 함께 사라진다.
- 인접 6방향 클릭 이동, 4방향(90° 단위) 아이소메트릭 회전 카메라, 층 강조 보기, 되돌리기/다시 하기/리셋, 점수와 별 3단계, 기록 저장을 지원한다.
- 레벨 18개(2D 튜토리얼 3개 + 3D 레벨 15개, 난이도 순 해금). 레벨은 텍스트 파일이라 추가가 쉽고, BFS 솔버가 풀이 가능 여부와 최적해를 검증한다.
- Java 17+ / Swing, **외부 라이브러리 없음**.
- 현재는 추가 기믹(연쇄 밀기, 계단, 리프트, 포탈, 중력)이 없는 **기본 게임**만 구현했다.

## 실행 방법

### 준비물

- JDK 17 이상 (`javac`, `java`가 PATH에 있어야 함)

### 실행

```bash
git clone https://github.com/shk0507jnu/sokoban-mouse-controls.git
cd sokoban-mouse-controls/sokoban
```

| 목적 | Windows | bash (Linux/macOS/Git Bash) |
|---|---|---|
| 컴파일 | `build.bat` | `./build.sh` |
| 실행 | `run.bat` | `./run.sh` |
| 단위 테스트 | – | `./test.sh` |
| 레벨 검증·최적해 기록 | `java -cp out sokoban.tool.LevelTool` | 〃 |

Windows에서는 `sokoban/run.bat`을 더블클릭하면 소스를 컴파일하고 실행한다. bash의 `run.sh`는 `out/`이 없으면 컴파일한다.
명령줄에서는 `sokoban/` 폴더에서 실행해야 `levels/`·`config/`를 찾는다
(다른 위치에서 실행하면 `-Dsokoban.home=폴더`로 지정).
기록은 `~/.sokoban25d/save.properties`에 저장된다(`-Dsokoban.save=경로`로 변경).

## 조작

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 평면 이동 (화면 기준: W 오른쪽 위, D 오른쪽 아래, S 왼쪽 아래, A 왼쪽 위) |
| `↑` / `↓` | 위(+z) / 아래(−z) |
| 마우스 왼쪽 클릭 / 터치 | 표시된 인접 칸 이동·상자 밀기 (위·아래층 포함) |
| `←` / `→` | 아이소메트릭 구도끼리 카메라 회전 (90°씩, 4방향) |
| Z / Y | 되돌리기 / 다시 하기 |
| R | 레벨 리셋 |
| Esc | 일시정지 |
| Tab | 층 강조 |
| V | 시점 초기화 |

마우스로 표시된 인접 칸과 상자를 직접 클릭해 이동한다. 위·아래층도 블록의 면을 클릭하면 된다.
호버한 칸을 강조하고, 상자를 밀 때의 도착 칸은 점선으로 표시한다(시점은 마우스로 돌리지 않는다).
카메라를 돌려도 이동 키는 항상 화면 기준이다.

## 검증

Java 17 대상으로 컴파일했으며 제공된 테스트와 클릭 이동 검증을 합쳐 **67개 테스트가 통과**했다.
클릭 대상은 인접한 칸에 한정되고, 위·아래층 상자 밀기와 구멍 메우기는 기존 엔진의 규칙을 그대로 사용한다.
`out/`·`out-test/` 및 플레이 기록은 저장소에 포함하지 않는다.
